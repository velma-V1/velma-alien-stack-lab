## Do not interpret 6,104 / 18,112 as VELMA accuracy

The aggregate deterministic success fraction is not a meaningful general capability score.

Phase A intentionally executes every one of 256 capability subsets against each of 64 diagnostic worlds. Most arms therefore omit one or more capabilities required by the world and are expected to remain valid unresolved evidence. Phase B likewise includes eight leave-one-out interventions and eight worlds intentionally outside the initial basis.

The purpose of these unresolved cells is causal attribution, not benchmark accuracy.

## Phase A — exact attribution

Phase A executed:

```text
64 diagnostic worlds × 256 capability subsets = 16,384 cells
```

The diagnostic set spans one-, two-, three-, and four-or-more-capability requirements. The minimum-basis map identifies the smallest capability subset that solves each diagnostic world under oracle TaskIR.

This phase is deterministic and uses zero neural model calls. It measures the reference atlas machinery under known formal representation; it does not establish natural-language or frontier-level intelligence.

## Phase B — oracle ceiling / leave-one-out

Phase B executed:

```text
192 worlds × 9 arms = 1,728 cells
```

The `FULL` basis solved **184 / 192** worlds. The remaining **8** are the preregistered outside-basis discovery probes, so the reference basis solved **184 / 184** worlds that were deliberately generated inside the initial basis under oracle TaskIR.

Each single-engine leave-one-out arm solved **136 / 192** worlds, losing 48 successes relative to the full-basis arm in this deliberately balanced synthetic generator. That symmetry is a property of the experimental design and must not be interpreted as evidence that all eight capability classes have equal real-world value.

## Synergy claim boundary

The implementation originally exposed co-required capability pairs in the map. A dedicated scientific-claim regression was then added and produced a real RED CI result because co-requirement is not enough to establish synergy.

That evidence has not yet been claimed.

## What is genuinely demonstrated

The current 010 implementation demonstrates that:

1. one TaskIR/ledger/report architecture can represent a heterogeneous eight-class computational basis;
2. the experiment can perform exhaustive subset intervention cheaply without neural inference;
3. all 18,112 deterministic Phase A/B cells can be sealed, executed, reconciled, and replay-identified in one CI run;
4. valid unresolved outcomes remain evidence instead of terminating the experiment;
5. outside-basis worlds remain distinguishable from infrastructure errors;
6. minimum-basis and leave-one-out attribution can be generated automatically;
7. missing live evidence remains explicitly pending instead of becoming a fabricated zero;
8. every initial capability receives a V31M4 Production Fitness Record without automatic promotion;
9. scientific-claim tests prevent co-requirement from being mislabeled as measured synergy.

## What is not yet demonstrated

The deterministic evidence does **not** establish:

- natural-language semantic compilation quality;
- representation generalization across real paraphrase/implicit inputs;
- live local-model routing quality;
- model-call reduction in a real VELMA workload;
- positive typed-dataflow synergy;
- real long-horizon performance;
- visual/perceptual understanding;
- real target-host CPU/RAM/latency economics;
- superiority to Opus or Fable;
- production readiness of any reference engine.

Those remain explicit later 010 phases/evidence additions rather than weaknesses hidden inside one aggregate score.
