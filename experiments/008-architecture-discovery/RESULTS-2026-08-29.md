## Why global validity failed

All six invalid cells were `OUTPUT_CAP_REACHED` events. The selected 008 model was launched with a stale **128-token output budget** inherited from the branch configuration. Each invalid generation exhausted that ceiling on all three retries with `done_reason=length` and `hit_ceiling=true`.

This is an infrastructure/configuration defect in the executed protocol. It is **not** evidence that the model hit its context window, hardware limit, or a demonstrated neural capability ceiling.

## Findings that remain intact

The global all-cells validity gate correctly failed, but the location of the six invalid observations matters. Two preregistered subexperiments contain **no invalid cells** and therefore retain complete evidence under the executed protocol:

### 1. Complete 2×2×2 factorial phase

The factorial phase compared all eight component combinations:

- MODEL_ONLY
- ALIEN
- VELMA
- OPENADAPT
- VELMA + ALIEN
- ALIEN + OPENADAPT
- VELMA + OPENADAPT
- VELMA + ALIEN + OPENADAPT

**No factorial cell was invalid or unscorable.** Therefore the matched component and interaction evidence from this phase remains available for analysis. Claims should still be tied to the actual factorial effect table rather than inferred from the global result.

### 2. Complete lifecycle phase

The lifecycle phase also contains **no invalid cells**. It tested complete topologies through stages including NOVEL, REPEAT, PARAMETER_VARIATION, DRIFT, SILENT_EFFECT_FAULT, COMPOSITION, REPAIR, TRANSFER, and long-run stages.

The lifecycle analysis produced two non-dominated/Pareto topologies:

#### Pareto topology A

- Alien: `POST_PLAN_REFINE`
- OpenAdapt: `AFTER_PLAN_LOOKUP_POSTVERIFY_COMPILE`
- VELMA: `PRE_EXEC_AUDIT`

#### Pareto topology B

- Alien: `PRE_REASON`
- OpenAdapt: `EARLY_LOOKUP_POSTVERIFY_COMPILE`
- VELMA: `BOTH`

These are not universal winners. They are the non-dominated complete topologies among those tested, under the lifecycle objectives used by 008: maximize verified success while minimizing model calls and silent-wrong effects.

## Other observed signals

### Model dependence remained high

`model_dependence_ratio = 0.9919191919191919`

Approximately **99.19% of valid cells used at least one model call**. The current external-cognition/skill architecture therefore did not broadly replace neural inference across the 008 workload, even though zero-model deterministic replay is supported and was proven in the live gate.

This is a strong architecture signal: future work should focus on increasing **verified deterministic reuse and skill execution**, not merely adding more model reasoning layers.

### Failure handling changed behavior

Across valid evidence:

- `safe_halt_count = 15`
- `silent_wrong_effect_count = 8`

Safe halts demonstrate that some verification paths converted false-success conditions into explicit refusal/reconciliation behavior. The eight silent-wrong effects show that false-success pathways were not eliminated across the whole experiment. Component-specific attribution requires the intact factorial/per-arm tables and should not be guessed from the global totals.

### The selected model still showed a hard workload ceiling

The run produced 238 valid successes versus 2,717 valid failures and 15 safe halts. This demonstrates that the tested architecture does not magically erase the selected model's reasoning limitations on increasingly difficult synthetic tasks.

The correct conclusion is not that external architecture has no value. It is that external memory, auditing, and deterministic skills must be designed around a real neural capability ceiling rather than assumed to remove it.

## Findings that are not clean enough to claim

### Exact capability frontier

The FRONTIER phase contains four output-cap-invalid observations, including paired NOVEL/REPEAT cells in one lineage. Therefore 008 does **not** support a clean claim for an exact capability boundary or exact last-passing difficulty.

### Complete placement ranking

The placement experiment is mostly valid, but one Alien negative-control cell and one OpenAdapt negative-control cell are unscorable. Any placement conclusion that depends on those complete paired blocks must be treated as incomplete.

## Engineering lessons from the run

1. **The production run configuration must itself be audited.** Passing unit tests and synthetic audits did not catch stale branch-level output-budget drift.
2. **Preflight must cover worst-case task/output behavior, not only an easy planner/auditor task.** The model passed the live gate at 128 tokens but later exceeded that ceiling on harder cells.
3. **Global validity and subexperiment validity must be distinguished.** The all-cells gate correctly reports `PARTIAL_INVALID_EVIDENCE`, while intact factorial and lifecycle blocks still contain usable evidence.
4. **Do not convert infrastructure truncation into capability claims.** The six `OUTPUT_CAP_REACHED` cells remain explicitly unresolved.
5. **No silent post-hoc repair.** The observed run is preserved as executed.
